## Projeto em destaque

### Medidor de batimentos cardíacos com Python

Projeto que estima a frequência cardíaca a partir de um código em **Python**, utilizando o princípio da **PPG (fotopletismografia)**, técnica que detecta variações no fluxo sanguíneo por meio de mudanças na absorção de luz.

- **Tecnologias:** Python
- **Conceito:** PPG (fotopletismografia)
